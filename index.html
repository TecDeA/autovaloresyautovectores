Autovalores, autovectores y subespacios propios

Introduce una matriz cuadrada A de tamaño n × n. La aplicación calculará su polinomio característico, sus autovalores (reales y complejos), una base de cada subespacio propio Eλ = Ker(A − λI) (ver qué significa) y las multiplicidades algebraica y geométrica.

¿Qué significa Eλ = Ker(A − λI)?

Definición. Sea A una matriz cuadrada de tamaño n × n. Un número λ es un autovalor de A si existe algún vector v ≠ 0 tal que A·v = λ·v; cada uno de esos vectores es un autovector asociado a λ. El subespacio propio asociado a λ es el conjunto formado por todos sus autovectores junto con el vector 0:

Eλ = { v ∈ ℝn : A·v = λ·v }

Restando λ·v en los dos miembros, la condición A·v = λ·v equivale al sistema homogéneo (A − λ·I)·v = 0, donde I es la matriz identidad de tamaño n. El conjunto de soluciones de un sistema homogéneo M·x = 0 se llama espacio nulo (o núcleo) de la matriz M. Por tanto:

Eλ = Ker(A − λ·I) = Nul(A − λ·I) = { v : (A − λ·I)·v = 0 }

Sobre la notación. Ker viene de «Kern» (núcleo, notación habitual en español) y Nul de «null space» (espacio nulo, usada en libros de texto en inglés, p. ej. el de D. C. Lay). Las dos designan exactamente lo mismo: el conjunto de todos los vectores que la matriz M envía al vector 0. Aquí usamos Ker; si λ es complejo, el conjunto vive en ℂn en lugar de ℝn.

Por qué es un subespacio. Como Eλ es el conjunto de soluciones de un sistema homogéneo, siempre es un subespacio vectorial: contiene al vector 0, y si u, w ∈ Eλ, entonces A·(u + w) = λ·u + λ·w = λ·(u + w) y A·(c·u) = c·(λ·u), de modo que u + w y c·u también pertenecen a Eλ. Su dimensión es la multiplicidad geométrica de λ, y una base se obtiene resolviendo (A − λ·I)·v = 0 por eliminación gaussiana–Jordan: cada variable libre aporta un vector de la base. Si la dimensión geométrica es menor que la algebraica, la matriz es defectuosa para ese autovalor y no será diagonalizable.

Ejemplo. Para la matriz A = [[2, 1], [1, 2]] (filas (2, 1) y (1, 2)), el polinomio característico es (λ − 1)·(λ − 3), luego los autovalores son λ = 1 y λ = 3, y E3 = Ker(A − 3I) = gen{(1, 1)}, la recta y = x. Pulsa «Cargar ejemplo» y «Calcular» para comprobarlo en la sección 3.

Puedes escribir enteros, decimales o fracciones (por ejemplo 1/2 o -3).
